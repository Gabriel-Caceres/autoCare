# AutoCare — Entrega 1 DSY1104

Tienda online frontend desarrollada con HTML5, CSS3 y JavaScript. Incluye tienda pública, catálogo dinámico, carrito persistente, formularios validados, autenticación simulada, roles y panel administrativo.

## Ejecución

1. Descomprimir el proyecto conservando su estructura.
2. Abrir `index.html` en un navegador moderno.
3. Para evitar restricciones locales del navegador, también se puede ejecutar con la extensión Live Server de Visual Studio Code.

## Funcionalidades principales

- Navegación pública entre Inicio, Nosotros, Blog, Contacto y Productos.
- Dos noticias con sus respectivas páginas de detalle.
- Registro con validación del RUN chileno y mensajes en tiempo real.
- Inicio de sesión y autorización por roles.
- Productos generados desde JavaScript.
- Carrito almacenado en `localStorage`.
- Compra y pedido simulados.
- CRUD local de productos y usuarios.
- Gestión y detalle de pedidos.
- Alerta cuando el stock alcanza el nivel crítico.
- Diseño responsivo mediante CSS externo.
